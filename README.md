# Raid Folder Navigator

React + Vite project: локальный каталог скриншотов по именам файлов.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
npm run preview
```

Готовая версия появится в папке `dist`.

## Как работает выбор папки

- В Chromium-браузерах на компьютере используется `showDirectoryPicker()`.
- В остальных браузерах используется стандартный выбор папки через `input` с `webkitdirectory` (если браузер его поддерживает).
- Подпапки также обходятся.
- В каталог попадают только файлы с графическими расширениями: PNG, JPG/JPEG, WEBP, GIF, BMP, TIF/TIFF.
- Приложение читает имя, относительный путь, размер и дату изменения файла из файловых метаданных.
- **Изображения не декодируются, не отображаются, не отправляются на сервер и не анализируются.**
- Определение локации — простое совпадение слов в имени файла (например, `woods`, `customs`, `лес`). Это не распознавание содержимого изображения.

## Важно

Выбор папки работает в локальном браузере. В некоторых браузерах API выбора папки требует защищённый контекст (HTTPS или localhost). Для надёжной работы запускай проект через `npm run dev` или размести его на HTTPS.

## Публикация на GitHub Pages

1. Создай публичный репозиторий с именем `raid-folder-navigator`.
2. Загрузи в него содержимое этой папки (не сам ZIP).
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **GitHub Actions**.
5. Создай workflow для Vite или используй готовый файл `.github/workflows/deploy.yml`, если добавишь его.
6. После успешной сборки сайт будет доступен по адресу `https://ТВОЙ-НИК.github.io/raid-folder-navigator/`.

`vite.config.js` уже настроен на путь репозитория `raid-folder-navigator`. Если назовёшь репозиторий иначе, измени `base` на `/<имя-репозитория>/`.
